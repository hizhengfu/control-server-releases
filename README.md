# ControlServer 下载

本仓库只提供 ControlServer 官方二进制发布包，不包含产品源码。

## 下载最新版

请前往 [Releases](../../releases) 下载最新版本。当前 Windows 便携包文件名为：

```text
control-server-windows-x64-base-video-voice.zip
```

同时下载同一版本中的 `SHA256SUMS`，并在运行前校验文件完整性。

## 安装和使用

Windows 用户请完整解压 ZIP，不要直接在压缩包中运行，也不要单独移动 EXE
或删除同目录的 DLL、模型资源。普通使用启动 `control-server.exe`。

首次设置、运行拓扑选择、项目播放、升级和排障请阅读
[ControlServer 使用说明](使用说明.md)。

如果系统提示未知发布者、签名异常或安全软件拦截，请先停止运行，确认下载
来源和 SHA-256 校验结果，不要直接忽略安全提示。
